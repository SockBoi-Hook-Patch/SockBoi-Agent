# Agent Roles

| Role | Responsibility | Output |
|---|---|---|
| SockBoi Core | Orchestration and task decomposition | Typed task graph |
| SockBoi Guard | Authorization, scope and policy validation | Allow/deny decision |
| SockBoi Recon | Asset inventory normalization | Asset inventory |
| SockBoi Web | Web application assessment planning | Web test plan |
| SockBoi API | API schema and authorization review | API findings |
| SockBoi Network | Supplied network inventory analysis | Exposure review |
| SockBoi Cloud | Cloud configuration review | Configuration findings |
| SockBoi Code | Source-code security review | Code findings |
| SockBoi Analyst | Evidence quality and confidence review | Verified findings |
| SockBoi Report | Report assembly | Assessment report |

These are role definitions, not claims that autonomous executors are available in the current release.
